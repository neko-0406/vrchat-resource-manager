# VRChat-Resource-Manager

vrchat用のリソースマネージャー

## Task

1. アセットのデータモデル定義:
   アセット名、カテゴリ、タグ、ファイルパス、サムネイル画像などを管理する構造の作成。
2. アセット登録機能の実装: AssetRegisterPage
   でアセットの情報を入力し、バックエンド経由でデータを保存する機能。
3. アセット一覧表示の実装: AssetPage
   で登録済みのアセットをカード形式などで表示し、検索やフィルタリングを行う機能。
4. アセットファイル操作: アセットのフォルダを開く、Unityにインポートするなどの補助機能。
